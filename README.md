# agente_Venegas
La decisión que decidir es sobre regar al cactus dependiendo el nivel de humedad en el suelo, debido que me llama la atención ese tema.
El agente obtiene la información del sensor de la humedad del suelo y dependiendo los datos propocionado por ellos, me dice la situación y que si autorizo o lo rechazo.
